Selected work

AI PDF Chat — retrieval over your own documents

FastAPI · LangGraph · Next.js

Upload a PDF, ask a question, get an answer that streams token by token and cites the page it came from. Retrieval runs as a LangGraph pipeline; the service boots with no API key, so the demo is reproducible from a fresh clone. Deployed on Render and Vercel.

Live · github.com/MrFox2000/ai-pdf-chat · 12 tests

News → Price Impact — an MCP agent

LangGraph · MCP · FastAPI · Next.js

Four tools — news search, price history, large-move detection and correlation — are served by a real MCP server. The agent plans, calls them over the protocol, and writes a report that pairs every large move with the headlines published in the days before it. The browser streams the agent's trace while it works.

Live · github.com/MrFox2000/agentic-news-impact · 26 tests

Django SaaS Starter — multi-tenant API

Django 6 · DRF · JWT · Stripe

Organisations, roles, plans and metered quotas. The active tenant travels inside the signed JWT, so a client cannot reach another organisation by editing a URL, and exhausting a plan returns 402 rather than a generic error. Complete OpenAPI schema, Docker image, Postgres.

Live API docs · github.com/MrFox2000/django-saas-starter · 29 tests

SaaS Dashboard — the client for that API

Next.js 16 · TypeScript · Tailwind 4

Role-aware controls, a live quota meter and a metered action whose 402 response becomes an upgrade prompt instead of a dead end. Strict TypeScript, no mocked data — every number on the page comes from the API.

Live · github.com/MrFox2000/next-dashboard · strict TS · CI
